4

Reliability gaps · the tradeoffs

tap a card · each speculative win has a failure mode + a mitigation
Speculative LLM ~700 ms
What firesDeep LLM call on a stable interim (≥3 words, confident). Cache lookup at speech_final.
✓ Saves ~700 ms on hit · ~95% hit rate in clean rooms
⚠ Stale match: interim grew between fire and final · cached answer is for the shorter prefix
MitigationProper-noun growth guard rejects matches where new trailing text contains capitalized words other than "I". MENTA_SPEC_ENABLED=false kills the track.
Speculative tools 100–500 ms
What firesPre-dispatch read-only tools (find_appointment, check_availability) when intent + entity present on the interim.
✓ Saves the backend round-trip when the LLM later asks for the same tool with matching args.
⚠ Side-effecting tools must NEVER be spec'd — would cause double-booking.
MitigationWhitelist in code; only registered read-only tools are eligible. Args-keyed cache so STT mishears miss cleanly.
Predictive retriever (RAG) 10–500 ms
What firesretrieve_async on the interim · LRU cache · take_result on speech_final.
✓ Saves the Moss / external vector DB round-trip.
⚠ Stale retrievals: docs pulled for interim phrasing may not match final question.
MitigationCache eviction when interim drifts more than 25 chars. Falls back to cold retrieve on miss.
TTS formatter warm 200–400 ms
What firesHaiku formatter on the speculative LLM result · normalises "911" → "nine one one", phone digits, dosages.
✓ Saves the formatter's LLM TTFT on the happy path.
⚠ Compound failure: if spec LLM was wrong, formatted text is wrong too. Both invalidate together.
Mitigationskip_format per-chunk bypasses formatter entirely.
