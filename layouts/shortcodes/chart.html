{{- /* chart: embed a self-contained HTML chart from /static/apps/ and size the iframe to its content, so short charts leave no dead space and tall ones are not clipped. Unlike {{< app >}}, this needs no cooperation from the embedded page. The iframe is same-origin, so /js/chart-embed.js measures the document directly and re-measures on resize, on font load and on content change. Plain self-contained HTML charts can be dropped into static/apps/ and embedded without modification. {{< chart src="roles-in-the-agent-era/soc-timeline.html" caption="..." >}} {{< chart src="roles/bls.html" caption="..." min="260px" >}} src path under /apps/ (a leading slash or full path is also accepted) caption optional figure caption rendered under the chart min height used before measurement, and the fallback if JS is off fit "off" to keep the iframe at `min` instead of growing to fit its content. Use it for tall interactive panels that scroll internally, so the embed does not become thousands of pixels high. title iframe accessible name (defaults to the caption) */ -}} {{- $src := .Get "src" -}} {{- if not (hasPrefix $src "/") -}}{{- $src = printf "/apps/%s" $src -}}{{- end -}} {{- $caption := .Get "caption" -}} {{- $min := .Get "min" | default "320px" -}} {{- $title := .Get "title" | default (cond (ne $caption "") $caption "Chart") -}} {{- $fit := .Get "fit" | default "on" -}} {{- if not (.Page.Scratch.Get "chartEmbedJS") }} {{- .Page.Scratch.Set "chartEmbedJS" true }} {{- /* fingerprinted so a change to the sizer is never served from cache */ -}} {{- $js := resources.Get "js/chart-embed.js" | fingerprint "sha256" }} {{- end }}
